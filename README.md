# MotoLedger 🏍️📊

**MotoLedger** is a multi-tenant business utility application built to handle the operational complexities of the used vehicle market. 

*Note: This repository serves as an archive for the compiled Android release (APK) of the application.*

## 🚀 Download & Installation

You can download and test the fully functional app directly on an Android device:

🔗 **[Download MotoLedger APK from Google Drive](https://drive.google.com/file/d/1XAKtvAPRLPO1kyTsxqVMaSF_UdJV-o1w/view?usp=drivesdk)**

**Installation Steps:**
1. Click the link above to download the `.apk` file to your Android phone.
2. If prompted by your device, allow your browser or file manager to "Install unknown apps" (this is a standard prompt for applications not downloaded from the Play Store).
3. Open the downloaded file and tap **Install**.

## 🛠️ Tech Stack & Architecture
- **Frontend Framework:** React Native, Expo
- **Backend & Database:** Firebase
- **Data Structure:** Multi-tenant architecture designed to ensure strict data isolation between different business users.

## ✨ Core Features
- **Inventory Management:** Track active used motorcycle stock and detailed vehicle specifications.
- **Expense Logging:** Log and monitor repair and maintenance costs associated with individual vehicles.
- **Sales History:** Maintain a comprehensive and searchable record of completed transactions.
